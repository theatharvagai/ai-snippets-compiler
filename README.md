A **language-independent**, real-time code snippet compiler that understands your intent and simulates execution using advanced AI. No more switching between environments for quick logic tests!

---

## ✨ Features

- **⚡ Real-time "As-You-Type" Compilation**: No buttons needed. Your code runs instantly as you finish typing.
- **🌍 Language Independent**: Works with Python, JavaScript, Rust, C++, or even natural language logic.
- **🤖 AI-Powered Engine**: Uses Google's Gemini AI (or local models) to interpret and execute snippets.
- **🎨 Minimalist Design**: A clean, distraction-free two-pane interface for maximum focus.
- **🖱️ Interactive Outputs**: AI can generate buttons and input fields dynamically based on your code's requirements.
- **⚙️ Flexible Configuration**: Easily switch between Gemini API and local model endpoints.

## 🚀 Quick Start

### 🛠️ Prerequisites
- [Node.js](https://nodejs.org/) (LTS recommended)
- A Gemini API Key (get it from [Google AI Studio](https://aistudio.google.com/))

### 📦 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/theatharvagai/ai-snippets-compiler.git
   cd ai-snippets-compiler
   ```

2. **Run via double-click:**
   Simply double-click the `run.bat` file. It will handle `npm install` and start the server for you!

   *OR manually:*
   ```bash
   npm install
   npm run dev
   ```

3. **Configure AI:**
   Click the ⚙️ icon in the app and paste your **Gemini API Key**.
